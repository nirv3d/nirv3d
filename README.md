## 🚀 Projects

### 🚗 Smart Driving Decision System
> Real-time AI driving assistant with object detection, risk scoring, and explainable decisions

- YOLOv8-powered detection of pedestrians, cars, and traffic signals from video/webcam input  
- Proximity estimation using bounding box heuristics + object prioritization  
- Risk-score based decision engine producing **STOP / SLOW DOWN / GO** with natural language explanations  
- Multi-threaded Flask backend with MJPEG streaming for smooth real-time inference  
- FastAPI microservice enabling external clients to consume decisions via REST APIs  
- Streamlit dashboard with live bounding boxes, color-coded risk levels, and decision overlays
